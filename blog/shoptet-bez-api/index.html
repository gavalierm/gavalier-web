Ako automatizovať Shoptet, keď nemáte prístup k API

Súkromné API má Shoptet podľa vlastnej dokumentácie iba v tarife Premium. Bez neho sa dá automatizovať cez export a import produktov: skript alebo AI upraví súbor a vy ho po malých dávkach nahráte späť.

Marcel Gavalier 23. novembra 2026 2 min čítania

API je iba v Premium

Podľa dokumentácie pre vývojárov je súkromné API súčasťou tarify Premium. V štandardných tarifách nie je. Ak ho nemáte, nie je to chyba nastavenia.

Export a import

Shoptet vie importovať produkty zo súborov XLSX, CSV a XML. Postup je jednoduchý: export, úprava skriptom alebo AI, kontrola a import. Pozor na tri pravidlá:

  • Prázdna bunka znamená „nemeň“. Vymaže ju až zapnutá voľba na mazanie.
  • Nula nie je prázdno. Pri cene sa nula uloží ako cena nula.
  • Varianty spája stĺpec pairCode. Varianty jedného produktu ho majú mať rovnaký a ísť hneď pod sebou. Inak vzniknú duplicitné produkty.

Bezpečný postup

  1. Pred importom si uložte export aktuálneho stavu. Shoptet to nevyžaduje, je to moje odporúčanie.
  2. Najprv nahrajte asi desať produktov a skontrolujte ich.
  3. Po importe urobte nový export a porovnajte ho s pôvodným.
  4. Importujte iba stĺpce, ktoré meníte.

Skript cez prehliadač

Niektoré veci sú iba v administrácii. Skript, ktorý ovláda prehliadač, je však krehký a Shoptet môže prístup zastaviť. Používajte ho iba tam, kde export a import nestačia, a pracujte pomaly. Ak vás Shoptet zastaví, skript má prestať a počkať.

Z praxe

Aplikácia pre klientsky e-shop pracuje hlavne cez export a import a časť dát číta cez prehliadač. Keď jej Shoptet raz zastavil prístup, dostala ochrannú pauzu: približne hodinu nečíta nič. Automatizácia má vedieť sama prestať.

Ak potrebujete oficiálny strojový prístup, jediná podporovaná cesta je tarifa s API.

Najčastejšie otázky

Má Shoptet API aj v bežnej tarife?

Nie. Podľa dokumentácie pre vývojárov je súkromné API súčasťou tarify Premium.

Dá sa Shoptet automatizovať bez API?

Áno, cez export a import produktov (XLSX, CSV alebo XML). Súbor pred nahratím skontrolujte a nahrávajte po malých dávkach.

Čo sa stane s prázdnou bunkou pri importe?

Nič, hodnota sa nezmení. Vymaže ju až zapnutá voľba na mazanie prázdnych hodnôt.
