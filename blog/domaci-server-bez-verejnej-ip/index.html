Ako sprístupniť domáci server z internetu bez verejnej IP adresy

Server bez verejnej IP adresy sprístupníte cez Cloudflare Tunnel. Program cloudflared na serveri sám otvorí spojenie smerom von, takže v routeri neotvárate žiadny port. Správu servera (administráciu, databázy, súbory) nikdy nesprístupňujte bez prihlásenia.

Marcel Gavalier 23. novembra 2026 2 min čítania

Ako Cloudflare Tunnel funguje

Podľa dokumentácie program cloudflared sám otvorí spojenie von do siete Cloudflare. Tunel preto funguje „without a publicly routable IP address“ a firewall môže blokovať všetko prichádzajúce.

Postup: nainštalujete cloudflared a vytvoríte tunel v dashboarde alebo cez API (Get started). Potom určíte, ktorú adresu má tunel posielať do ktorej služby.

Dočasná a stála adresa

Rýchly tunel s adresou na trycloudflare.com nevyžaduje účet ani doménu. Podľa dokumentácie:

  • je „for testing and development“,
  • zvládne najviac 200 súbežných požiadaviek,
  • má „no uptime guarantee“,
  • adresa sa pri každom novom tuneli zmení.

Na stálu službu použite bežný tunel s vlastnou doménou.

Čo nikdy nesprístupniť bez prihlásenia

Tunel neurčuje, kto smie poslať prevádzku. Bez prihlásenia nesprístupňujte:

  • administráciu servera, routera a NAS,
  • monitorovacie panely,
  • databázy,
  • vzdialenú plochu a príkazový riadok,
  • súbory a zálohy,
  • rozhrania programov (API), ktoré konajú za vás.

Pre ľudí použite Cloudflare Access (dokumentácia). Službu volanú programom musí chrániť vlastný kľúč a bez kľúča má odpovedať chybou.

Kedy radšej VPN

Ak službu potrebujete len vy alebo váš tím, nevystavujte ju a pripájajte sa cez VPN. Verejná adresa má zmysel pre cudzích ľudí alebo programy mimo vašej siete.

Z praxe

Na vlastnom serveri bez verejnej IP mám služby cez tunel. V novembri 2026 som jednu presunul z dočasnej adresy na stálu na vlastnej doméne, cez ten istý tunel. Neoveril som správanie tunela pri veľkom objeme prenosu.

Najčastejšie otázky

Potrebujem na Cloudflare Tunnel verejnú IP adresu?

Nie. Program cloudflared otvorí spojenie smerom von, takže verejná IP ani otvorený port v routeri nie sú potrebné.

Čím sa líši rýchly tunel od bežného?

Rýchly tunel je na testovanie, nemá zaručenú dostupnosť, zvládne 200 súbežných požiadaviek a adresa sa pri každom spustení mení. Na stálu prevádzku slúži bežný tunel.

Je server cez tunel automaticky chránený?

Nie. Tunel prenáša prevádzku, ale neurčuje, kto ju smie poslať. Služba musí mať prihlásenie (napríklad Cloudflare Access) alebo vlastný kľúč.
