AI poradenstvo

Čo sú skills a hooks v Claude Code a ako nimi naučím AI agenta svoj postup

Skill je postup pre Claude Code zapísaný v súbore SKILL.md. Načíta sa, až keď ho úloha potrebuje. Hook je príkaz, ktorý sa spustí vždy v určitom bode práce. Skill agenta učí, ako postupovať. Hook mu zabráni urobiť, čo nesmie.

Marcel Gavalier 23. novembra 2026 2 min čítania

Čo je skill

Podľa dokumentácie Claude Code je skill priečinok so súborom SKILL.md. Leží v .claude/skills/.

Súbor začína záhlavím. Pole description určuje, kedy sa skill použije. Zvyšok je postup:

---
name: nasadenie
description: Použi, keď sa nasadzuje web na ostrú doménu.
---
1. Over, že si na vetve main a strom je čistý.
2. Spusti kontrolu odkazov.
3. Až potom nasaď a over výsledok na živej adrese.

Skill sa spustí sám, keď popis sedí na úlohu. Alebo ho vyvoláte príkazom.

Skill alebo CLAUDE.md

Súbor CLAUDE.md sa načíta pri každej relácii. Patria doň stále fakty a konvencie. Skill sa načíta, až keď sa použije, preto sa hodí na dlhý postup.

Čo je hook

Podľa sprievodcu hookmi sú hooky vaše príkazy, ktoré Claude Code spúšťa v pevných bodoch práce. Hook sa vykoná vždy. Nastavuje sa v settings.json.

  • PostToolUse beží po použití nástroja. Napríklad po úprave súboru spustí formátovač.
  • PreToolUse beží pred použitím nástroja a môže ho zablokovať. Skript skončí s kódom 2 a Claude dostane vysvetlenie.

Pokyn alebo hook

  • Pokyn alebo skill stačí pri postupe a úsudku. Chyba je opraviteľná.
  • Hook treba, keď pravidlo nesmie zlyhať. Pokyn model môže prehliadnuť, hook nie.

Ako vyzerá dobrý skill

  • Popis hovorí, kedy sa skill použije.
  • Kroky sú číslované a na konci je overenie.
  • Dôležité rozhodnutia potvrdí človek.

Z praxe

V mojom systéme AI agentov sú opakované postupy skilly a pravidlá, ktoré sa nesmú porušiť, vynucujú hooky. Po každej chybe doplním skill. Hook napríklad odmietne zmenu mimo priradeného pracovného adresára.

Zdroj tvrdení o nástrojoch: Claude Code dokumentácia: skills a hooks.

Najčastejšie otázky

Čím sa skill líši od CLAUDE.md?

CLAUDE.md sa načíta pri každej relácii a hodí sa na stále fakty. Skill sa načíta, až keď sa použije, preto sa hodí na postupy.

Môže agent hook obísť?

Hook beží mimo modelu, takže sa vykoná vždy, keď nastane jeho udalosť. Dokumentácia však upozorňuje, že zablokovanie úprav súborov nepokrýva príkazy v shelli.

Musím vedieť programovať, aby som napísal skill?

Nie. Skill je text v bežnej reči s krátkym záhlavím. Hook je spravidla krátky skript.
